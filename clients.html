Windows 客户端配置指南

适用于 Windows 10 / Windows 11 (64位与ARM架构)
推荐软件： Clash Verge Rev (首选) v2rayN Sing-box

在 Windows 系统上，目前最稳定且现代化的代理客户端首选 Clash Verge Rev（基于开源内核），支持原生暗黑模式、TUN 虚拟网卡全流量接管，并具备极低内存占用。

STEP 01

下载与安装

从 GitHub Release 或对应机场下载中心获取 x64-setup.exe 安装包。运行安装并勾选开机启动。

STEP 02

导入订阅链接

登录机场后台复制 Clash 订阅 URL。在 Verge 侧栏进入【订阅 (Profiles)】，粘贴地址并点击【导入 (Import)】。

STEP 03

开启代理与 TUN

在设置中开启【系统代理】。若玩外服游戏或让命令行/UWP走代理，点击安装服务模式并开启【TUN 模式】。

STEP 04

规则分流模式

在【代理】界面将路由模式选为【规则 (Rule)】，点击延迟测试按钮选低延迟节点，国内直连、国外专线加速。

⚠️ Windows 常见故障排查：

  • 关闭软件后电脑无法上网： 这是由于退出时系统代理注册表未被注销。在 Windows 设置 > 网络和 Internet > 代理 中，将“使用代理服务器”手动关闭即可恢复。
  • 7890 端口冲突报错： 本地存在其他代理软件占用了 7890 端口。在设置中将 Mixed Port（混合端口）修改为 7895 或 10809 即可。
  • 订阅更新失败提示 403： 在订阅链接末尾加上 &flag=clash，或在订阅右键菜单中更换 User-Agent 为 clash-verge。

macOS 客户端配置指南

适用于 Apple Silicon (M1/M2/M3/M4) 及 Intel 架构
推荐软件： Clash Verge Rev (首选) ClashX Meta Surge Mac

Mac 用户推荐使用适配 Apple Silicon 的原生客户端，不仅发热量极低，还能通过 Privileged Helper 辅助工具实现全局底层网络接管。

STEP 01

架构选择与安装

苹果 M 系列芯片下载 aarch64.dmg，Intel 芯片下载 x64.dmg。拖拽至 Applications。若提示未受信任，在“安全性与隐私”中点击“仍要打开”。

STEP 02

授权服务与增强模式

初次启动进入设置，点击安装【系统扩展服务 (Privileged Helper)】，输入 Mac 开机密码授权，开启高权限虚拟网卡。

STEP 03

订阅导入与自动更新

进入【Profiles】，粘贴机场订阅链接保存，并设置自动更新周期为 1440 分钟（24小时），保证节点信息最新。

STEP 04

智能出境分流

在菜单栏图标中选择【出境规则模式 (Rule)】，系统自动根据目标域名选择最优直连或代理线路，不影响日常微信/B站。

⚠️ macOS 常见故障排查：

  • Mac 休眠唤醒后断流： 系统休眠后网络接口被重置，在设置中勾选“网络断开时自动重启核心”；或在菜单栏快速关闭再打开系统代理。
  • 终端 Terminal 无法连接海外： 终端不默认走 GUI 代理，可输入命令配置临时环境变量：export https_proxy=http://127.0.0.1:7890。
  • Safari 提示证书不安全： 检查客户端的 MitM（中间人解密）或本地 DNS 设置，通常关闭不必要的主机覆写即可恢复正常。

iPhone 与 iPad (iOS) 配置指南

适用于 iOS 15 / 16 / 17 / 18 及 iPadOS 系统
推荐软件： Shadowrocket (小火箭) Stash Quantumult X

iOS 平台的网络加速客户端需要在非国区（美区/港区/日区）App Store 中下载，最为经典、易用且生态完备的首推 Shadowrocket (小火箭)。

STEP 01

获取海外 ID 下载

在 App Store 登录美区或港区 Apple ID 购买下载小火箭。特别警告：切勿在系统【设置-iCloud】中登录他人账号！

STEP 02

一键导入订阅

Safari 打开机场后台，点击【一键导入小火箭】自动拉起应用；或在右上角点【+】，类型选 Subscribe 粘贴链接。

STEP 03

授权添加 VPN 配置

首次滑动顶部连接开关时，系统弹出“添加 VPN 配置”窗口，点击【允许】并输入 iPhone 锁屏密码或通过 Face ID 验证。

STEP 04

全局路由选择“配置”

在小火箭首页将【全局路由】选为【配置 (Config)】，千万不要选全局代理，避免微信等国内应用消耗专线流量。

⚠️ iOS 常见故障排查：

  • 所有节点全部变红 Timeout： 90% 的原因是手机系统时间不准确。在 iPhone 设置 > 通用 > 日期与时间 中开启“自动设置”，偏差超 60 秒会导致 TLS 握手失败。
  • 订阅更新失败返回 404/500： 机场订阅链接可能已重置。回到机场后台重新复制最新的订阅链接，并在小火箭中下拉列表手动刷新。
  • 需要开启全天候免看护： 在小火箭设置中开启【按需连接 (On Demand)】，可在离开 Wi-Fi 切换到 5G 移动蜂窝网络时自动无缝保持连接。

Android 客户端配置指南

适用于 小米 MIUI/HyperOS、华为鸿蒙、OPPO、vivo 及 原生安卓系统
推荐软件： Clash Meta for Android v2rayNG Surfboard

Android 平台生态自由度高，推荐安装基于 Clash Meta 内核的 Clash Meta for Android (CMFA) 或 v2rayNG，完全免费开源且支持所有新型专线协议。

STEP 01

安装与权限授予

从官方 GitHub Release 或机场下载中心获取 .apk 安装包，安装并允许创建本地 VPN 连接与常驻通知权限。

STEP 02

导入配置 (Profiles)

点击主界面【配置 (Profiles)】 > 【新配置】 > 【从 URL 导入】，粘贴机场后台复制的专属订阅链接并点击右上角保存。

STEP 03

后台保活防杀进程

在手机系统设置中，将应用省电策略改为【无限制】，开启【允许自启动】与【允许后台活动】，多任务界面锁定卡片。

STEP 04

开启分流与应用绕行

在主界面点击【启动】开启连接。在分流模式中确认选为【规则 (Rule)】，可在应用绕行中勾选不走代理的国内应用。

⚠️ Android 常见故障排查：

  • 锁屏后几分钟断流无法接收海外推送： 国产系统（小米/华为/OPPO）激进清理后台导致进程被杀。务必在系统电池优化中开启“后台保活无限制”，并在任务管理器中下拉“加锁”。
  • 连接后国内网页卡死： 检查路由设置中是否开启了“绕过局域网及大陆地址”规则，避免将国内 CDN 流量通过代理绕行。
  • 无法通过手机热点共享代理给 Switch 或电视： 在设置中开启【允许局域网连接 (Allow LAN)】并记录端口号即可。

通用上手 4 步法则

  • 一、获取订阅：先在官网注册并复制专属订阅链接
  • 二、下载正版：认准开源发布页，远离来路不明的破解版
  • 三、设置规则：务必使用 Rule 分流模式，不浪费流量
  • 四、测试排查：遇网络异常先测试节点延迟，排除本地断网
